## Контроль качества — 120/120 проверок пройдено

- 16:9, единый шрифт Segoe UI, явный фон `<p:bg>` на 100% слайдов, бейджи и нумерация.
- Заметки докладчика с источником (файл + страница) и статусом на 100% слайдов.
- Ни одного безусловного «входит в СЭЗ»: везде «планируемый режим / при получении статуса СЭЗ»
  (исправлены Park стр. 25, Investor стр. 9, Hub100 стр. 9).
- «по данным прокуратуры» удалено из истории автодрома (Park стр. 5) → «по публикациям СМИ [предварительно]».
- Xiaomi Auto / MG / VOYAH — только с пометкой «участие не подтверждено».
- Сохранены атрибуции: AutoFlight (© Tengrinews.kz / Болат Айтмолда; съёмка 24KZ; видео производителя),
  карты (© OpenStreetMap contributors, Natural Earth, OSRM, Esri), Duisburg (по данным DGT и duisport).
- Слайды-визуалы без текста получили видимые подписи: Animated 10–12, 16, 25; Hub100 11–13, 16, 23;
  Investor 11–13, 16, 21; Park 3, 32–33 (альт-описания в заметках).
- Дорожные карты получили диапазоны дат 2027–2030 / 2030–2035 / после 2035 с пометкой [TBD].
- Слайд ERG в «Алатау» — с оговоркой об обязательном одобрении ERG.
- CAPEX, рабочие места, контакты, спикер форума — структурированные плейсхолдеры
  «[Уточняется инициатором / TBD]» (ничего не выдумано).
